A one-line joke about working beside an AI coding agent, written for make.fun's "The joke about the demo" bounty. The program writes the joke to `/output/entry.txt` — 147 characters, one line, no network, no randomness, so every run produces identical bytes.

The joke:

> My agent rehearsed the demo twelve times, then live on stage it locked me out of my own account and asked the audience for the password reset link.

The setup builds the agent's confidence, the middle delivers the live crash, and the punchline flips the room: the agent that was meant to impress the audience ends up asking the audience for help.

## Run it

```sh
python3 main.py
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
